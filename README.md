# SUIPA — Página Institucional

Landing page institucional da SUIPA (Sociedade União Internacional Protetora dos Animais), criada pela DevMedia como projeto educacional colaborativo.

## Sobre este projeto

Esta página foi desenvolvida com fins educacionais pela [DevMedia](https://www.devmedia.com.br), plataforma de ensino de programação, e faz parte da trilha **Dominando o Git e GitHub**.

O objetivo é que alunos em aprendizado possam praticar contribuições em projetos reais — fazendo fork, criando branches e abrindo pull requests — em um repositório público com propósito concreto: divulgar o trabalho da SUIPA.

> **Esta página não representa o site oficial da SUIPA.**
> Acesse o site oficial em [suipa.org.br](https://www.suipa.org.br).

## Tecnologias

HTML e CSS.

## Estrutura de arquivos

- `index.html`: página principal com apresentação institucional da SUIPA
- `style.css`: estilos gerais do projeto
- `assets/`: imagens utilizadas no projeto

## Como visualizar

Abra o arquivo `index.html` diretamente no navegador.

## Como contribuir

1. Faça o fork deste repositório
2. Crie uma branch com a sua contribuição
3. Implemente a melhoria proposta
4. Abra um pull request descrevendo o que foi alterado e por quê

Veja as instruções completas no checkpoint da trilha na plataforma DevMedia.
